# AfterClass — Discover what drives you

A minimal local-first prototype: reflect → discover → explore. Setup, demo and
test instructions are in [the app README](./afterclass/README.md).

App directory: `/Users/mac_m5/Documents/GitHub/Cline-Hackathon/afterclass`.
Requires Node.js 24 and an API key for OpenAI, Gemini, Claude, or a supported
OpenAI-compatible service; no Supabase setup is needed. See the app README for
provider, model, and base URL configuration.

The prototype uses local SQLite storage and required Login ID/password accounts—no anonymous option.
It includes
longitudinal discoveries, 100 labelled example activities across many subjects,
catalogue browsing and privacy controls. Live web-data features are disabled.
Cloud setup and hosting: `afterclass/DEPLOYMENT.md` (no deployment yet).
